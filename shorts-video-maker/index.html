Two tools in one

What it does

Tool 1 · Automatic

Quiz Video Maker

  • Fill in a form: question, code, four options, explanation (Markdown works). Press Create video.
  • Runs your Python, JavaScript or PHP code and fills in the real output for you.
  • Built to keep viewers: hook line, “pause and comment” prompt, countdown timer, confetti answer reveal, mascot, sound effects.
  • Two voices: one asks the question, a second announces the answer. Lo-fi background music that dips while someone speaks.
  • IDE-style code card with VS Code, Dracula and GitHub colours, in 9 languages.
  • Day 1 / Challenge 3 numbering, a ready-to-upload queue with title, description and hashtags, and bulk actions for many videos at once.
Tool 2 · Your own videos

Studio editor

  • A timeline editor with a live phone preview that matches the final video.
  • Add typing code (you set the speed), text, boxes, circles, arrows, pictures (transparent PNG works) and spoken voice-over lines.
  • Drag objects on the preview. Set where something starts, where it ends and when it moves, with green S and red E markers.
  • Keyframes for move, rotate, scale and fade, with smooth, bounce and overshoot easing.
  • Undo and redo, auto-save, background music, and a library you can search by type, category, language and tag.
  • Start from a template: typing code, move things around, compare two things, quick tips.

Questions

FAQ

Do I need to know how to code to use it?

No. You use it in the browser: fill in a form and press a button. The one-time setup is something I can do for you.

Does it upload to YouTube by itself?

Not yet. It makes the MP4, prepares the title, description and hashtags, and keeps track of what you already posted. Automatic upload can be added as a custom feature.

What do I need to run it?

A computer with PHP, MySQL and Python 3 (Windows, macOS or Linux). It runs on your own machine, so your questions and videos stay with you.

Can it make videos about topics other than programming?

The quiz format works for any multiple-choice question. The Studio editor is open-ended: text, shapes, pictures and voice-over can show any topic.

Can I see it working before I decide?

Yes. Message me and I'll make a short video from your own questions so you can judge the result.

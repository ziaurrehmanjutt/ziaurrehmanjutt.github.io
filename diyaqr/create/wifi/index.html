How it works

  1. Type the network name (SSID) exactly as it appears on your router.
  2. Enter the password and choose the security type, usually WPA.
  3. Download the QR code and print or share it.
  4. Guests point their camera at it and tap to join.

Questions

Which security type should I choose?

Most routers use WPA / WPA2 / WPA3, so pick WPA. Choose "No password" only for open networks.

Is it safe to put my Wi-Fi password in a QR code?

Anyone who can scan the code can join, just like anyone who sees the written password. Put it only where guests should see it, and change the password if you need to revoke access.

What if my network name is hidden?

Tick "Hidden network" so phones know to look for it.

Mga na-save kong code

Dito lalabas ang mga code na sine-save mo. Nakaimbak lang ang mga ito sa browser na ito, hindi sa server.

Paano ito gumagana

  1. Ilagay ang email address ng tatanggap.
  2. Magdagdag ng opsyonal na paksa at mensahe.
  3. I-download ang code.
  4. Kapag na-scan, magbubukas ang mail app na handa na ang lahat.

Mga tanong

Awtomatiko bang maipapadala ang email?

Hindi. Magbubukas ang mail app na may nakalagay nang draft at ang tao mismo ang pipindot ng Send.

Comment ça marche

  1. Mettez votre menu en ligne en accès public, par exemple sur votre site ou via un lien PDF partagé.
  2. Collez le lien dans le générateur.
  3. Ajoutez vos couleurs et votre logo, puis téléchargez en SVG ou PNG.
  4. Imprimez-le assez grand pour que les téléphones puissent le scanner à distance normale.

Questions fréquentes

Puis-je changer le menu plus tard sans nouveau QR code ?

Oui, si le lien pointe vers un fichier que vous pouvez remplacer (par exemple un PDF avec le même lien) ou vers une page de votre propre site. Le QR code ne stocke que le lien.

Où dois-je placer le code ?

Sur les chevalets de table, les menus, les tickets de caisse et l'entrée. Gardez-le à plat et bien éclairé.
